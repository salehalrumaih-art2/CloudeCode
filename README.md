# SEEDRA Presentation Design System

The official design system and style guide for Seedra Ventures presentations.

## Contents

- **[SEEDRA-Presentation-Design-System.md](./SEEDRA-Presentation-Design-System.md)** — The comprehensive design reference covering colors, typography, layouts, components, spacing, and usage rules.

## Purpose

This repository serves as the single source of truth for all Seedra Ventures presentation design. Designers should reference this guide when creating new presentations to ensure brand consistency.

## Quick Start

1. Read the [Design System](./SEEDRA-Presentation-Design-System.md) document in full before starting your first presentation.
2. Use the **Slide Layout Catalog** (Section 6) to select the right layout for your content.
3. Follow the **Slide Construction Checklist** (Section 13) before finalizing each slide.
